# Face Recognition System

A Python-based face recognition project developed using OpenCV and the face_recognition library.

## Overview

This project explores facial recognition and image processing using Python. It includes experiments with face detection, face encoding, face comparison, and recognition using stored reference images.

## Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy

## Project Structure

- `Face_recognition Project.py` — Main face recognition program
- `Capturing an Image.py` — Image capture functionality
- `Learning cv2 library.py` — OpenCV experiments
- `Learning face_recognition library*.py` — Experiments and learning implementations

## How It Works

The system captures or loads an image, detects faces, generates facial encodings, and compares them against known face encodings to determine whether a face matches a stored reference.
